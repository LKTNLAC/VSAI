# VSA India – Hội Sinh viên Việt Nam tại Ấn Độ

Website chính thức của Hội Sinh viên Việt Nam tại Ấn Độ (VSA India).

## Tính năng

- 🌐 Bilingual (Tiếng Việt / English)
- 📱 Responsive cho mọi thiết bị
- 🗺️ Bản đồ tương tác với Leaflet.js
- 📸 Thư viện ảnh với Lightbox
- 📰 Tin tức, Blog, Hoạt động, Cẩm nang
- 👥 Ban Chấp hành
- 🔍 Filter và tìm kiếm

## Công nghệ sử dụng

- HTML5
- CSS3
- Vanilla JavaScript
- JSON cho dữ liệu
- Leaflet.js cho bản đồ

## Deploy

Website được deploy trên GitHub Pages.
